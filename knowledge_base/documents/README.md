# Source document files

Place publisher-obtained documents in domain-specific folders only when redistribution is permitted by the publisher's licence or terms.

Suggested folders:
- `ITU_Framework/`
- `Tanzania_Health_Policies/`
- `Public_Health_Guidelines/`
- `Public_Health_AI_Case_Studies/`

Do not commit confidential health records, patient-level data or copyrighted PDFs without permission. When redistribution is not permitted, retain the official URL and metadata in `../source_register.csv` and use an authorised upload workflow at runtime.

The presence of a folder or manifest entry does not mean a document has been downloaded, parsed or indexed.
